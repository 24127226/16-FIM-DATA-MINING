\section{Introduction}
\label{sec:01_introduction}

Frequent Itemset Mining (FIM) constitutes a foundational task in data mining, underpinning association rule discovery, retail market basket analysis, event-log diagnostics, and visual pattern extraction. This project implements the Eclat algorithm~\cite{zaki2000scalable} from scratch in Julia~1.11.4, verifies exact equivalence against the SPMF reference implementation~\cite{fournier2014spmf}, evaluates empirical performance across standard benchmarks, and demonstrates two end-to-end real-world applications.
